# Blog App Ariel

## Descripción
Aplicación en React que muestra publicaciones y comentarios usando la API JSONPlaceholder. Permite buscar, filtrar por usuario y navegar entre páginas.

## Cómo ejecutar la aplicación

### Requisitos
- Node.js (v22 o superior)
- npm (v10 o superior)


### Ubuntu / Linux
```bash
git clone https://github.com/AR00212/blog-app-ariel.git
cd blog-app-ariel
npm install
npm start
