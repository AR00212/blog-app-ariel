# Blog App Ariel

## Qué es ?
Esta es una aplicación web hecha en React que muestra publicaciones y comentarios usando la API JSONPlaceholder.  
Puedes:  
- Ver una lista de publicaciones con paginación.  
- Buscar publicaciones por título o contenido.  
- Filtrar publicaciones por usuario.  
- Ver detalles y comentarios de cada publicación haciendo clic en ella.  

Todo está hecho con componentes reutilizables para que el código sea más limpio y fácil de mantener.

---

## Cómo ejecutar la aplicación

### Requisitos
- Node.js (v22 o superior)  
- npm (v10 o superior)  
- Navegador moderno (Chrome, Firefox, Edge)

### Ubuntu / Linux, Windows y MacOS
```bash
# Ubuntu / Linux
git clone https://github.com/AR00212/blog-app-ariel.git
cd blog-app-ariel
npm install
npm start

# Windows
git clone https://github.com/AR00212/blog-app-ariel.git
cd blog-app-ariel
npm install
npm start
# Nota: Instalar Node.js desde https://nodejs.org/ (v22 o superior)

# MacOS
git clone https://github.com/AR00212/blog-app-ariel.git
cd blog-app-ariel
npm install
npm start
# Nota: Instalar Node.js desde https://nodejs.org/
